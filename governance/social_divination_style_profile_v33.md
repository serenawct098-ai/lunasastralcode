# 社群占卜／療癒文風規則檔 v3.3

> **狀態**：`design_rule`。本檔只規範 Luna's Astral Code 的可變社群文案；不構成命理規則、古籍引文、心理診斷、財務建議或對第三人行為的事實判斷。
>
> **適用範圍**：Hook、正文、置頂解答、完整解讀與視覺卡中可替換的 `［］` 文案。
>
> **不適用範圍**：固定模板、CTA、卡數、版面、色碼、動態盤象五元組、型式三／四的 SSOT 術語、公式與引用。

## 1. 聲音定位

這是一種「靈性解讀＋情緒安撫＋低門檻行動」的社群文風。直接以第二人稱「你」說話，像替讀者說出卡住的感受，但不替讀者宣告其經歷，也不替第三人下結論。文本的目的，是把讀者從不安帶回可觀察、可決定的下一步。

## 2. 五步文案節奏

每一段可依篇幅選用下列鏈條；短文至少完成第 1、2、4、5 步，長文可完整使用五步。

| 步驟 | 作用 | 合格寫法 | 禁止寫法 |
|---|---|---|---|
| 1. 代入 | 指出一個普遍、可辨識的困擾 | 「你可能一直想等一個更清楚的答案。」 | 捏造職業、對話、身體症狀、精準時間或未提供經歷。 |
| 2. 拉扯 | 命名兩種同時存在的感受或選擇 | 「想放下，又怕自己太早離開。」 | 用矛盾堆砌營造被說中的感覺。 |
| 3. 轉述 | 用同一判準重看困擾 | 「你在意的未必是答案，而是這段等待是否還值得。」 | 假對比，例如「不是沒有機會，而是你還沒問清楚」。 |
| 4. 行動 | 提供一至兩個低風險、可完成的選擇 | 「先把你真正想問的事寫下來，再決定要不要開口。」 | 要求分手、投資、辭職、就醫或其他高風險行動。 |
| 5. 自主收束 | 把主導權還給讀者 | 「你可以慢一點決定，不必為了害怕失去而勉強自己。」 | 保證結果、命定論或以焦慮逼迫互動。 |

## 3. 詞彙與術語規則

日常臺灣中文是主體。優先使用「想、等、問、停、看、分清、放回、決定、回應、界線」等可感知的動詞，少用空泛程度詞與行業黑話。每段最多使用一個主要生活領域，例如關係、工作、等待、選擇或日常節奏。

命理、靈性或品牌詞可以出現，但只能依現有資料亮牌，且必須立刻白話轉譯。術語負責定位，不得取代解釋。詞語如「能量、頻率、磁場、宇宙」只屬品牌語境，不得暗示醫療、法律、財務或可驗證因果。

| 層次 | 使用原則 | 範例 |
|---|---|---|
| 日常情緒詞 | 優先使用，讓讀者看懂自己正在面對什麼 | 等待、拉扯、放心、卡住、失望、分清。 |
| 生活行動詞 | 每段至少有一個可執行動作 | 問清楚、停一下、整理、回應、設定界線。 |
| 命理／靈性詞 | 僅依 SSOT 或已登錄五元組使用，後接白話 | 「白話來說，這次要你先把最急的一件事處理清楚。」 |
| 禁用 AI 腔 | 不用它代替具體感受或行動 | 本質上、底層邏輯、賦能、靜默力量、能量消耗、共振。 |

## 4. 句型、節奏與標點

標題要短，讓讀者一眼知道正在談的困擾。正文以中長句描寫一個狀態，再用短句完成重述、行動或收束。不要連續短句製造口號感，也不要把背景、象徵、結論和建議全部塞進同一句。

可使用「你不是……，而是……」「如果你想要……，先看……」「當你……，再決定……」等句型，但必須維持前後同一判準。問句只用於真實選項或反思；驚嘆號只放在必要高點；冒號用於模板允許的欄位化說明；括號只補註已登錄術語。中文內的英文、數字與專名依既有全形標點及中英空格規則處理。

## 5. 權威與自主邊界

文案可以提供解讀，不可以把解讀寫成讀者或第三人的已證實事實。避免「你一定會」「他不會回來」「注定」「只要……就會……」等句子。若談感情、財富或未來，焦點必須回到讀者可觀察的回應、選擇、界線與下一步，而不是替對方定性或保證結果。

## 6. 型式套用提醒

型式一與型式五依已登錄動態盤象撰寫；型式三與型式四依 SSOT 撰寫。無論型式為何，文風規則只能調整白話場景、情感推進與行動表達，不能反寫、補造、刪改或混用命理真值。

## 7. 發布前文風自檢

- [ ] 是否以第二人稱自然說話，而非替讀者捏造經歷？
- [ ] 是否先有具體困擾，再有合理重述與低風險行動？
- [ ] 是否保留讀者主導權，沒有保證外部結果或替第三人斷言？
- [ ] 是否先以日常中文說清楚，再使用必要且可回查的術語？
- [ ] 是否長短句交錯，且每句只承擔一個主要意思？
- [ ] 是否完全未改動固定模板與命理資料邊界？

## 8. 來源與維護

本檔的聲音特徵來自使用者於本任務提供的占卜／療癒型社群貼文截圖，以及其完成的質性文風分析。來源定位見 `governance/style_source_provenance.md`。日後新增或修訂規則時，必須先確認只影響可變文案，並以獨立 Audit 記錄來源、範圍、Diff 與驗證結果。
